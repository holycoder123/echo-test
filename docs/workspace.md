# EchoTest

面向 Windows 桌面应用的低代码自动化测试工作台，支持坐标 / 截图定位、操作录制、可编辑步骤、图片断言和本地执行报告。Electron 负责桌面界面，Python / OpenCV / Win32 负责定位、录制和执行。

## 启动

从 [GitHub Releases](https://github.com/holycoder123/echo-test/releases) 下载安装版或便携版及 SHA256 校验文件。每个发布版本对应同名 Git 标签；版本说明见 [v1.0.0](releases/v1.0.0.md)。

安装版运行 `dist/echo-test-1.0.0-setup-x64.exe`，按中文向导安装后从桌面或开始菜单启动。支持选择安装目录、桌面快捷方式及卸载，升级和卸载保留用户用例、录制及报告。详细规则与构建方式见 [Windows 安装版](installer.md)。

双击 `start.cmd`，软件默认通过 Windows UAC 请求管理员权限；确认后打开工作台，取消则不启动。已具有管理员权限时不会重复请求。`start_admin.cmd` 仍兼容。打开工作台后选择并连接目标窗口，目标应用保持原生独立窗口。

默认双击启动、桌面快捷方式及 `npm start` 均请求管理员权限并开启 MCP。关闭当前主窗口后，可用 `start_no_mcp.cmd` 禁用本次启动的 MCP；接入方式见 [MCP 接入](mcp.md)。

窗口列表显示有标题且客户区有效的可见顶层应用窗口，不按应用名称筛选，并排除 EchoTest 自身窗口。右上角支持按窗口标题、进程名或 PID 搜索，可用空格组合多个关键词；搜索不区分大小写。搜索不会断开当前连接，刷新保留搜索词；只有一个匹配结果时可点击「连接」，多个结果从列表选择。启动时不会自动连接任意应用。

连接后默认使用捆绑在目标应用右侧的纵向工具栏，宽约 380 像素，高度接近目标窗口；窄屏会适当缩小宽度。右侧优先，空间不足时按可用区域摆放，目标应用分辨率保持不变。拖动任一窗口会带动另一个窗口，最小化和恢复也会联动。工具栏上的「解绑」可恢复自由移动，再点「捆绑目标应用」重新连接；录制或执行期间暂停切换捆绑。

便携版内置 Node.js、64 位 Python、Electron、OpenCV、OCR 依赖和中英文模型。解压 `dist/echo-test-win-x64.zip` 到可写目录后双击 `start.cmd`，无需另装 Node.js 或 Python，也无需联网。支持 Windows 10/11 x64；若新电脑缺少 Visual C++ 运行库，启动器会使用包内的微软安装器补齐，需要确认系统管理员提示。

从只有源码的目录准备运行环境时，联网运行 `install_dependencies.cmd`；制作完整 ZIP 使用 `build_portable.cmd`。`runtime` 保存项目私有运行环境，随项目整体移动；不要只复制源码而遗漏 `runtime` 或 `node_modules`。依赖清单、离线验证和构建说明见 [便携运行包](portable.md)。自定义 Python 路径仍可通过 `ECHO_TEST_PYTHON` 指定。

## 通用控件库

「通用控件库」由所有用例共享，切换或新建用例不会更换控件库。可以新增、改名或删除分类，并按控件名称、分类或 OCR 识别文字搜索；点击步骤的「目标控件」或「拖动终点」，会弹出控件库选择窗口，支持分类、搜索、缩略图和选中控件的图片预览，确认后填入步骤；选择图片断言或等待图片时只显示图片／OCR 控件。修改控件后，引用它的用例会使用最新配置；被用例或锚点引用的控件不能删除。

仓库初始不包含用例、控件、分类或模板图片，启动时进入空白用例。后续导入的用例中的控件会自动迁入，相同配置复用，同名但配置不同的控件保留为不同条目。共享定义保存在 `control_library/controls.json`，共享图片保存在 `test_cases/assets`；备份或移动整个工作区时保留这两处。保存用例时仍附带实际引用控件的快照和模板，便于单独移到其他工作区。

## 日常使用

1. 连接目标应用，在「录制」页或窗口工具栏点击「开始录制」。
2. 手动操作目标应用，点击「停止录制」或按 F12。
3. 将录制结果转换为用例，检查步骤并添加图片断言。
4. 保存到 `test_cases`，在「测试用例」页查看全部已保存用例。
5. 运行用例，在「运行记录」查看报告；功能报错可在「错误日志」查看详情。运行记录中的执行日志、历史报告和错误日志支持逐条勾选或全选当前列表后删除，操作前会确认；删除报告包含该次运行的截图与脚本输出。

`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。用例旁的 `assets` 保存图片模板，移动用例时一起移动。

左侧「使用说明」内置离线指南，支持搜索和目录跳转，覆盖连接目标应用、录制重放、控件识别、用例运行、报告和常见问题。独立工具栏标题栏的「?」也可打开；工作台或工具栏获得焦点时按 `F1` 打开。

## 目录与文档

| 目录 | 用途 |
|---|---|
| `control_library/` | 跨用例共享的控件定义、分类和旧控件迁移记录 |
| `electron/`、`echo_test/` | 桌面界面与 Python 后端源码 |
| `electron/tests/`、`tests/` | Node 与 Python 测试 |
| `scripts/`、`electron/tools/` | 安装、验证启动与手动诊断 |
| `test_cases/`、`projects/` | 用户用例、附带示例与历史邮件用例 |
| `recordings/`、`reports/` | 原始录制与执行历史 |
| `artifacts/` | 验证结果和诊断截图 |
| `.runtime/` | 工作台运行状态和诊断信息 |
| `docs/` | 详细说明 |

- [使用指南](user-guide.md)：目标应用连接、录制、控件、断言、邮件用例与日志。
- [项目结构](structure.md)：完整目录、模块职责和数据存放约定。
- [开发与验证](testing.md)：单元测试、界面冒烟和原生窗口回归。
- [MCP 接入](mcp.md)：让普通权限的 Codex 通过管理员工作台截图、在内存中探索少量步骤，验证后再保存正式用例。
- [Python 脚本](python-scripts.md)：编写或导入 `.py` 步骤，调用目标应用操作、跨步骤变量、超时和停止。

## 开发

```powershell
npm start
npm run test:all
npm run test:ui
```

界面冒烟结果保存到 `artifacts/smoke`。实际目标应用回归见开发文档，需使用与目标应用匹配的权限。

运行上述检查可验证当前版本。测试数据在临时目录生成，不向真实应用发送回放输入。
