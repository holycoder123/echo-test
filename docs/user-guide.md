# 使用指南

面向 Windows 桌面应用的低代码自动化测试工作台。界面采用浅灰侧栏、步骤卡片和属性面板；Electron 负责桌面界面，Python / OpenCV / Win32 负责定位、录制和执行。现有 JSON 用例继续兼容。

## 启动

双击 `start.cmd`。安装版和便携版自带运行环境；只有源码时先运行 `install_dependencies.cmd` 安装依赖。

软件默认请求管理员权限：双击 `start.cmd`、桌面／开始菜单快捷方式或运行 `npm start` 后，确认 Windows UAC 提示即可。已有管理员权限时直接启动，取消权限确认则停止启动。旧的 `start_admin.cmd` 入口仍兼容。目标应用的窗口访问和输入需要匹配权限，普通权限可能返回错误码 5。启动编辑器不会自动执行用例。多个目标应用通过右上角下拉框明确选择。

## 工作台与目标窗口

目标应用在工作台启动后才打开时，点击右上角「刷新目标窗口」，再从下拉框选择客户端。右上角搜索框按窗口标题、进程名称或 PID 筛选，可用空格组合关键词，不区分大小写。清除搜索恢复完整列表；刷新会保留搜索词。搜索不触发连接，也不会断开当前连接，未匹配搜索的当前连接仍单独保留。只有一个匹配窗口时点击「连接」即可；多个结果需要从列表明确选择。刷新只更新可选列表；连接成功后指示灯才变绿。只有一个客户端时，可直接点击「连接」；连接失败或需要重试时使用「连接／重新连接」按钮。连接后使用目标应用原生窗口与右侧工具栏。

| 页面 | 功能 |
|---|---|
| 目标窗口 | 打开原生目标应用旁的工具栏，进行录制、停止、坐标 / 图片采集和执行 |
| 测试用例 | 添加操作、拖动排序、复制和删除步骤，在右侧直接编辑参数，保存和运行 |
| 控件库 | 管理坐标和图片控件，从目标应用截图取点或框选模板，导入图片，预览定位 |
| 录制 | 手动操作目标应用，停止后查看转换结果，追加到当前用例或创建新用例 |
| 运行记录 | 查看步骤日志、结果和本地 HTML 报告 |
| 使用说明 | 离线阅读入门流程、控件配置和常见问题，支持搜索和目录跳转；工具栏「?」或 F1 也可打开 |

表单修改直接生效，点击“保存”写入磁盘。`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。用例标题旁的圆点表示有未保存修改。“更多”菜单提供新建、打开、另存为。

## 在工具中操作目标应用

目标应用保留原生标题栏、样式和分辨率。连接后，纵向工具栏默认捆绑在目标应用右侧，宽约 380 像素、高度接近目标窗口，窄屏会适当缩小宽度；右侧优先，空间不足时按屏幕可用区域摆放。拖动目标应用或工具栏都会带动另一个窗口，最小化和恢复也会联动，工作台仍可单独移动。

工具栏上方为录制与坐标 / 图片采集，中间选择用例、设置循环次数并查看进度；步骤结果默认展开，长名称和错误详情自动换行，运行区域独立滚动。下方提供错误日志和工作台入口，标题栏的「?」打开使用说明。点击目标应用连接信息旁的「解绑」可自由移动工具栏，再点「捆绑目标应用」恢复联动；录制或执行期间不可切换捆绑。屏幕不足以同时容纳两个完整窗口时会提示换到更大的屏幕或解绑。

关闭工具栏不关闭目标应用，左侧「目标窗口 ↗」可重新显示。切换客户端、断开连接或正常退出工作台会解除捆绑。目标应用获得焦点时，Alt+F4 仍是目标应用自己的关闭快捷键。窗口回归和界面冒烟见 [开发与验证](testing.md)。

## 运行用例

窗口工具栏及工作台目标应用页的「运行用例」下拉框可以选择当前编辑内容，或本地用例库中的已保存用例；可设置循环次数、刷新列表和启动执行。选择已保存用例后，点击运行时加载该用例；当前内容有未保存修改时，会先显示未保存修改提示，可取消并先保存，或确认替换。

运行状态显示实际运行的用例名称、当前步骤、轮次 / 重复次数、耗时、进度和通过 / 失败数量。展开「各步骤结果」查看每个步骤最近一次执行的结果，失败原因直接显示在状态区域。完成、失败或停止后保留结果；执行期间锁定用例和循环次数，可以点击「停止执行」或按 F12 中止。工作台「测试用例」页也可运行当前编辑内容，在「运行记录」查看报告。

## 自定义 Python 脚本

自定义逻辑可使用「添加步骤」→「Python 脚本」，支持直接编写、展开编辑和导入 `.py`，代码随用例保存。可调用当前目标应用控件、按键和截图，输出及异常写入报告，支持超时和 F12 停止。完整 API 与示例见 [Python 脚本步骤](python-scripts.md)。

测试用例支持低代码模式与 Python 模式。低代码可添加循环步骤组和变量，在文本中用 `${i}` 引用循环编号；顶部可预览生成代码或创建独立 Python 副本。Python 模式右侧可搜索控件并插入函数参数引用。创建副本保留低代码原稿，两份内容分别保存；任意 Python 修改不自动反向转换。详细操作见 [两种用例模式](python-scripts.md#两种用例模式)。

## 初始数据

仓库不附带预置用例、控件或模板图片。首次启动进入空白用例，在窗口列表中明确选择应用后，可以新增控件或开始录制。录制结果、用户保存的用例和控件由当前工作区保存。

窗口发现不按产品名称筛选，显示有标题和有效客户区的可见顶层窗口，排除 EchoTest 自身窗口；运行时校验窗口句柄、进程身份和焦点。

## 从手动操作生成用例

1. 右上角连接目标应用，打开窗口工具栏。
2. 点击窗口工具栏的“开始录制”；目标应用自动获得操作焦点。
3. 手动完成操作。鼠标点击、双击、右键、长按、拖动、滚轮和键盘按下 / 松开会被捕获。
4. 点击窗口工具栏的“停止录制”或按 **F12**，工作台显示录制结果，查看事件与生成步骤。F12 被其他程序占用时使用停止按钮。
5. 可先点击“重放录制”，将本次生成的步骤执行一次；按 **F12** 或点击“停止重放”中止。重放结束后回到录制结果，显示进度、步骤状态和报告入口，仍可再次重放。
6. 选择“追加到当前用例”或“创建新用例”，检查步骤，添加图片断言，再保存。

重放保留本次录制和当前编辑用例的未保存内容，使用当前连接的目标窗口。空录制或未连接目标应用时不能重放；执行期间不能追加、创建或丢弃录制。重放执行生成的测试步骤，原始事件仍保存在本机。

录制仅捕获所选目标应用的输入，鼠标必须命中实际目标窗口，键盘焦点必须位于目标应用；点击工具栏和编辑表单不会混入脚本。忽略本工具生成的回放输入、Windows 键和作为停止快捷键的 F12；不再统一丢弃被 Windows 标为模拟输入的触摸或远程操作。定位自动转为比例坐标，并合并同一位置的控件。拖动保留采样轨迹，键盘保留按下 / 松开的顺序与间隔。

原始事件和转换结果自动保存在 `recordings`，即使放弃导入也保留文件。录制得到的步骤可以继续编辑，坐标控件可以替换为图片控件。

录制转换使用顺序步骤：复杂的鼠标与键盘重叠操作不能保证逐毫秒还原；中文输入法候选、粘贴内容无法仅从物理按键恢复，请编辑为“输入文本”步骤。录制不会自动生成业务断言，需补充图片验证。

## 第一个商城用例

1. 打开附带的“打开商城”示例，连接目标应用。
2. 在控件库编辑“商城按钮”，从目标应用截图取点校准位置。
3. 手动打开商城，在截图中框选稳定的商城标题，创建图片控件。
4. 在单击步骤后添加“图片存在”，引用商城标题控件。
5. 保存并运行，在运行记录查看报告。

Windows 接收输入调用不等于目标应用状态已经改变。图片断言用于验证商城真正打开。

## 通用控件库、分类和搜索

控件库与当前用例独立。所有用例使用同一个「通用控件库」，新建或打开其他用例后，控件仍可见。步骤设置中的目标和拖动终点直接按分类列出共享控件；用例只保存实际引用的控件及其锚点依赖。

- 在左侧选择「全部控件」「未分类」或自建分类。新增、编辑控件时，可以选择分类。
- 「新建分类」创建分类，「管理」可改名或删除分类。删除分类会将控件移至「未分类」，不会删除控件。
- 搜索支持控件名称、分类名称、定位类型及 OCR 文字；多个搜索词按同时匹配过滤，搜索可与分类叠加。
- 修改共享控件的名称、位置、图片或识别设置后，其他引用它的用例在加载或执行时使用最新定义。稳定引用使改名后步骤仍能找到同一控件。
- 删除控件时会检查当前未保存用例、已保存用例和其他控件的锚点引用。需要先移除引用或修改步骤，再保存相关用例。

旧用例无需逐条手动搬迁：首次使用会读取现有用例，把控件和模板迁入共享库，不覆盖原用例文件。相同名称与配置的控件复用，同名但配置不同的控件自动添加编号。录制转换产生的控件也进入共享库。

共享库定义和分类位于 `control_library/controls.json`，模板位于 `test_cases/assets`。完整备份需保留这两处；安装升级和卸载会保留共享库。单独保存或另存用例仍附带引用快照和模板，导入其他工作区时会恢复为共享控件。

## 定位和事件

坐标以目标应用客户区左上角为原点，不含标题栏，支持像素和 0～1 比例坐标。图片控件可以选择「图片模板」或「OCR 文字」识别，支持阈值、搜索区域和点击偏移。旧用例继续使用原来的灰度模板匹配，无需转换。

在「控件库」编辑图片控件时，可使用下列设置：

| 设置 | 使用方法 |
|---|---|
| 附加模板 | 使用「框选附加模板」或「导入附加模板」添加正常、悬停、选中等状态，最多 10 张。执行时比较所有模板和配置倍率，选择通过校验的最高分候选。 |
| 定位锚点 | 选择已经建立的图片 / OCR 控件，例如面板标题；搜索区域改为相对锚点匹配框左上角的 `X, Y, 宽, 高`，X/Y 可为负数。例：`-20, 30, 300, 180`。这些值为客户区像素，不随锚点倍率缩放；锚点消失时不退回全屏找图。循环引用会被拒绝。 |
| 颜色容差 | 留空关闭。启用后比较模板与候选的 RGB 像素差异，0 最严格、255 最宽松，可以从 40 开始用预览校准。适用于颜色表示选中 / 未选中、可用 / 不可用状态的控件。 |
| 模板遮罩 | 在主模板或某张附加模板旁导入遮罩图；尺寸必须与该模板一致。亮度达到 128 的像素参与匹配，其余忽略。推荐黑白 PNG：白色保留文字和边缘，黑色覆盖动画、倒计时等变化部分。遮罩同步参与颜色校验。 |
| OCR 文字 | 填写目标文字，选择「整行一致」或「包含目标文字」。匹配时忽略空白、大小写和全角 / 半角差异，阈值检查 OCR 置信度。点击识别到的整行中心，可用点击偏移校准；短文字宜限制搜索区域。 |

「预览定位」不发送点击。成功时显示匹配框与点击点；失败时显示橙色最佳候选框、分数、倍率和未命中原因，候选不足时只有原因。颜色校验启用时显示候选颜色差异。分数不是正确率，调整参数时也应测试目标不存在的画面。执行报告的「识别诊断」保留每个步骤最后一次识别信息，失败时另存带候选框的原始识别截图。

便携版已内置本地 RapidOCR / ONNX Runtime 中英文模型和 64 位 Python，优先使用 `runtime/python` 私有环境。运行 `verify_portable.cmd` 检查；缺少文件时重新解压完整便携包，只有源码的目录可联网运行 `install_dependencies.cmd` 准备环境。自定义 Python 路径通过 `ECHO_TEST_PYTHON` 指定。OCR 首次初始化通常比模板定位慢，后续使用缓存的引擎；识别效果需要用实际目标应用字体和截图校准。

模板应包含稳定文字或边缘，避免动画和纯色区域。重复图案可通过搜索区域缩小范围。分辨率、皮肤、UI 比例变化后应重新校准。

| 事件 | 配置 |
|---|---|
| 单击、双击、右键 | 目标控件；双击间隔 |
| 长按 | 控件、按住时间、鼠标按钮 |
| 拖动 | 起点、终点、时间；录制可保留轨迹和鼠标按钮 |
| 滚动 | 控件、方向、格数 |
| 等待图片、图片存在、图片不存在 | 图片控件、超时 |
| 按键组合 | 例如 CTRL+A、ENTER、F1 |
| 按下 / 松开按键 | 保留移动键、组合操作的按住过程 |
| 输入文本 | Unicode 文本，先点击输入框聚焦 |
| 等待、保存截图 | 等待时间、目标应用客户区截图 |

步骤可启用 / 禁用、重复和设置后续等待，整个用例也可循环。失败立即停止。执行前检查目标窗口、焦点、遮挡和实际输入 API 结果；停止按钮及 F12 中止执行，并释放已按下的按键和鼠标。

目标应用需要在可交互桌面中完整显示。管理员身份并不能保证客户端接收模拟输入；失败时查看报告中的具体 API 错误。录制监听安装成功也不代表目标应用回放成功，两者应分别验证。

录制、执行和截图采集时，工作台让出前台，等待目标应用激活，操作完成或启动失败后恢复。激活失败和运行中失焦会显示实际前台窗口名称，不会继续发送输入。前台授权只交给本应用的测试服务，采用 [AllowSetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-allowsetforegroundwindow)，不修改系统的焦点限制设置。

## 错误日志与录制诊断

左侧「错误日志」可按等级筛选、搜索功能或日志编号，点「详情」查看错误堆栈、Python 异常、请求耗时和当时的连接状态。独立窗口工具栏也有「错误日志」入口；可打开日志目录或导出最近 1000 条 JSONL 记录。

日志保存在 `%APPDATA%\echo-test\logs`，单文件约 2 MB，保留最多 5 个文件，重启后仍可查看。审计连接、录制、采集、运行、用例保存、窗口切换及服务 / 界面异常。日志不包含用例内容、输入事件、截图或输入文本。

录制按钮显示启动过程，只有监听就绪后开始计时。上一段录制未处理时，会打开结果页；启动失败会恢复按钮并显示日志编号。录制启动后 8 秒仍没有事件，或停止时没有事件，会保存诊断提醒（权限、目标应用句柄与进程、前台句柄、监听线程、观察到的事件数量），方便判断焦点、权限或监听问题。监听回调异常会保留已有录制结果并报告原始错误。

零事件结果会显示「未录到操作」和采集诊断提示，可直接点击「重新录制」启动监听，原始录制文件仍保留。包含任何事件的结果需要先追加、创建用例或明确丢弃，不能通过重试覆盖。

## 本地用例库

根目录 `test_cases` 是新建用例的默认保存位置；另存为也默认使用此目录。支持子目录，图片模板由原有保存功能复制到用例旁边的 `assets` 目录。旧用例仍按原路径保存。

「测试用例」页顶部显示全部本地已保存用例：递归扫描 `test_cases`、旧 `projects`，并列出通过工作台打开或保存过的其他本地文件。可搜索名称 / 路径、刷新、打开用例目录和点击打开用例。列表显示步骤数、控件数、修改时间及当前正在编辑的用例；打开前保留未保存修改提示。保存后自动更新列表，返回页签和重新激活工作台也会刷新。报告、原始录制和草稿不会作为用例显示，损坏的 `.echo.json` 文件会显示读取错误。



## 删除日志与运行报告

「运行记录」中的执行日志、历史报告，以及「错误日志」均支持行勾选、全选当前列表和「删除所选」。可以只勾选一项，也可以勾选多项；修改错误日志的等级或搜索条件会重置勾选，避免误删隐藏记录。新到达的记录不会自动加入之前的全选。

历史报告列表显示最近 100 份，错误日志默认显示最近 300 条；全选只选择当前列表中的记录。每次删除都需要确认，执行或录制期间不可删除。删除报告会同时删除该次运行的截图和脚本输出；清除页面执行日志只影响该页面记录，保存的报告独立管理。错误日志删除会写回本机日志文件，重启后仍生效。
