# echo test v1.0.0

面向 Windows 桌面应用的通用自动化测试工作台。此版本统一产品名称为 echo test，并首次通过 GitHub Releases 提供完整离线发行包。

## 更新

- 移除游戏窗口内嵌模式，目标应用保持独立原生窗口，可使用右侧捆绑工具栏。
- 窗口连接不限制应用名称，支持按标题、进程名、PID 及组合关键词搜索。
- 通用控件库由所有用例共享，支持分类、搜索，以及带图片预览的目标控件选择窗口。
- 默认启动请求 Windows 管理员权限并开启 MCP。
- 执行日志、历史报告和错误日志支持逐条选择及全选当前列表后删除。
- 修复控件库卡住、无效模板读取，以及控件弹窗关闭和取消按钮失效。
- 新安装不包含预置用例、控件、分类或模板图片。

## 下载与启动

支持 Windows 10/11 x64。安装版按向导安装，便携版完整解压后运行 `start.cmd`。两种发行包均内置 Electron、Node.js、Python、图片识别依赖及中英文 OCR 模型，无需另装 Node/Python。默认启动需确认 Windows UAC 提示。

安装包尚未做数字签名。下载后使用 `Get-FileHash -Algorithm SHA256 文件路径`，与同版本 `.sha256` 或 `SHA256SUMS.txt` 核对。

每个 Release 绑定同名源码标签 `v1.0.0`。发行包的 `runtime/release.json` 记录产品版本、源码提交和标签；运行环境依赖清单见 `runtime/manifest.json`。

## 数据与升级

升级前保存用例并关闭工作台。安装版升级保留用户用例和通用控件；卸载保留用例、控件、报告及录制数据。旧名称版本使用不同的安装目录和用户配置目录，已有数据请先备份，再按 [便携运行环境](../portable.md) 的目录约定迁移。
