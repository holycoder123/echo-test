# EchoTest 1.2.1-beta

本地预发布构建，面向 Windows 游戏／客户端测试开发者。此 Beta 首先交付优化方案的「完成第一条测试」与「修复一条测试」流程。安装包和便携包包含运行环境、编辑器与离线 OCR 模型。

## 新工作区

- 指选或搜索连接 Windows 目标后，直接进入测试用例工作区。目标信息常驻顶部，左侧显示本地用例，中间编辑步骤或 Python，右侧检查目标与参数，底部查看本次运行。
- 工作区里的「录制」默认追加到当前低代码用例；选中步骤可选择「在此后录制」。F12 停止后，结果自动加入草稿。原始录制仍保存在本机；空录制或转换失败回到录制结果页处理。
- 刚加入的录制可以一键撤销。继续修改用例后，撤销入口自动收起，避免覆盖后续编辑。
- 未保存内容自动写入当前电脑的恢复点，下次启动可显式恢复或丢弃；恢复不会自动连接目标或执行用例。正式用例仍需 Ctrl+S 保存。自动恢复只保留一个当前草稿，清理应用配置可能移除恢复点。

## 录制位置与共享控件

- Windows 和安卓新录制的点击、长按、滚动及拖动起终点，直接保存在步骤中，不再自动创建共享坐标控件。
- 步骤右侧显示「本步位置」，支持编辑比例／像素坐标、偏移、截图重新取点、定位预览及改用图片定位。拖动起点和终点独立设置。修改端点后清除旧轨迹，按新起终点直线拖动；未修改端点时保留原轨迹。
- 需要复用时，点击「保存为共享控件」，命名后保存并让本步引用。主动新建的共享坐标控件继续支持。
- 旧版自动生成且未分类的录制坐标收进「历史录制位置」，默认列表和控件选择器不再混排；旧引用保持兼容。手动保存或分类后作为普通共享控件管理。
- 「整理当前用例录制位置」先检查引用，再确认转换，仅修改当前草稿。含 Python（包括停用脚本）的用例、其他已保存用例仍引用的位置、无法检查的用例会被保护；不删除共享定义，不覆盖已保存文件。整理后仍需保存用例。
- 用例继续使用 schema_version 1，位置存于步骤参数 `position` / `end_position`；运行、重放、Python 转换和 MCP 均支持。生成的 Python 按执行时客户区大小换算坐标。

## 手动添加步骤

点击「添加下一步」并选择操作后，明确选择「本步坐标」「图片定位」或「已有共享控件」，不再默认引用第一个控件。图片可选择已有模板／OCR，或新建并采集；拖动分别设置起点和终点。完成配置后才加入用例，中途取消不留下半配置步骤。无需目标的按键、文本、等待等步骤直接加入。

## 创建验证

1. 录制打开背包、商城或任务面板。
2. 点击「添加验证」，在目标截图中框选稳定的标题或图标。
3. 命名目标，选择「应该出现」「应该消失」或「等待出现」。
4. 可先预览定位，再点击「加入测试步骤」。验证插入在所选步骤后；空用例插入为第一步。

高级识别设置保留模板、OCR、阈值、遮罩、倍率、锚点与搜索区域。截图标注为手动采集／预览，不表示实时画面。

## 局部试跑与失败修复

- 选中步骤后可执行本步、执行勾选片段、运行到这里或从这里运行。勾选首尾之间的步骤会连续执行。局部运行固定为一轮，不修改原用例的启用状态。
- 选区碰到循环时扩展为完整循环组，保留原步骤编号。被禁用的循环不会被局部运行重新启用。范围外的准备步骤、变量赋值和脚本状态不会自动恢复；请手动准备目标状态。
- 报告名称明确标注「局部试跑」及范围，局部通过不代表整条测试通过。Python 主程序仍按完整程序执行。
- 在工作区执行失败时，自动选中失败步骤，并展示错误、失败截图、已有的识别诊断、候选匹配分数和搜索区域。可直接预览当前定位、重跑本步或打开完整报告。
- 「重新采集副本」生成一个新目标，仅替换当前步骤的引用，保留原共享控件。新目标继续使用现有共享控件存储与稳定 ID；图片／OCR 控件仍使用共享库；录制坐标已改为步骤内的位置。高级修改共享控件前会提示影响所有引用用例。

## 兼容与后续范围

保留 schema_version 1、旧用例、Python 编辑、安卓设备、录制结果页、共享控件库、MCP 和 CLI。这次新增的连续工作区录制以 Windows 低代码用例为主；安卓保持原设备页流程。

准备／清理钩子、共享子流程、项目依赖打包向导、批量 CI 与标准报告扩展属于后续交付；AI 自动修复、引擎 SDK 与云设备管理未在此版引入。

## 试用与验证

便携版：解压 `echo-test-1.2.1-beta-portable-x64.zip` 到可写目录，运行 `start.cmd`。

安装版：运行 `echo-test-1.2.1-beta-setup-x64.exe`。同目录安装会更新程序文件，请先关闭旧工作台。发行包从空用例和空控件库开始，不携带开发工作区的测试资产、录制、报告或本机连接凭证。

自动验证包含源码检查、Node/Python 单元回归，以及无目标输入的 Electron 界面冒烟。Beta 专项覆盖录制加入／撤销、本步位置编辑与重采集、显式共享、历史位置整理、创建验证、定位预览、草稿恢复、局部运行请求、失败截图及修复副本，检查 1120×740 与 1440×900 布局。真实游戏的输入兼容性和识别成功率需要另用对应客户端验收，自动界面测试不替代实机测试。
