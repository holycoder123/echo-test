# EchoTest v1.0.1

新增工作台设置，改进目标窗口选择与鼠标指选性能。

- 设置页包含快捷键、MCP、启动与关闭、目标窗口、报告与日志五个分类，支持导入、导出和分组重置。
- 支持自定义全局快捷键及冲突检查，保留 F12 紧急停止；支持 MCP 启停、复制连接配置、重置连接和默认探索超时。
- 支持启动权限、窗口位置、托盘关闭行为、窗口刷新、默认搜索与工具栏偏好。
- 历史清理先预览范围和占用空间，确认后删除；保留用例、控件及录制数据。
- 目标窗口页面提供鼠标指选与搜索列表，支持最小化窗口、按标题/进程/PID 搜索和连接身份校验。
- 分离鼠标监听与窗口扫描、高亮更新，修复指选时的鼠标卡顿；保留 Esc/F12 取消与异常清理。
- 包含 MCP 少量步骤探索接口，返回执行结果和截图，验证后再保存正式用例。

下载 `echo-test-1.0.1-setup-x64.exe` 安装版，或解压 `echo-test-1.0.1-portable-x64.zip` 便携版后运行 `start.cmd`。适用于 Windows 10/11 x64，内置 Node、Python、Electron 及本地 OCR 环境。

升级前保存用例并关闭工作台。安装版升级及卸载保留用户用例、通用控件、报告和录制数据。本机设置保存在 `%APPDATA%/echo-test`。

使用 `Get-FileHash -Algorithm SHA256 文件路径` 与 `SHA256SUMS.txt` 或对应 `.sha256` 核对。安装包尚未做数字签名。

发行包绑定同名源码标签 `v1.0.1`；包内 `runtime/release.json` 记录版本、源码提交、标签和构建地址。
