# EchoTest v1.1.0

新增低代码与 Python 双模式、循环变量及窗口 API 代码补全。

- 低代码模式支持循环步骤组、嵌套与递减循环、变量赋值，以及 `${变量名}` 文本替换；循环组可整体移动、复制、禁用和删除。
- Python 模式支持编写或导入整个用例，在控件库中搜索、预览并插入稳定 ID 引用，控件可作为内置操作或自定义函数的参数。
- 支持只读预览低代码生成的 Python、创建独立 Python 副本及返回低代码原稿，分别保存两种编辑内容。
- Python 自动化主接口统一为 `window.xxx`；历史 `game` 调用保持兼容，旧用例继续可用。
- 三个 Python 编辑入口均支持 `window.` 函数联想、名称筛选、参数签名和中文说明；支持方向键、Enter/Tab、鼠标选择、Ctrl+Space 与撤销/重做。
- 执行报告增加循环变量和脚本操作记录，完善执行进度、循环规模限制、脚本超时及 F12 停止。
- 改进下拉选择器样式，并修复通用控件删除时的当前引用检查。

下载 `echo-test-1.1.0-setup-x64.exe` 安装版，或解压 `echo-test-1.1.0-portable-x64.zip` 便携版后运行 `start.cmd`。适用于 Windows 10/11 x64，内置 Node、Python、Electron 及本地 OCR 环境。

升级前保存用例并关闭工作台。安装版升级及卸载保留用户用例、通用控件、报告和录制数据；本机设置继续使用 `%APPDATA%/echo-test`。新增模式与流程控制应使用 v1.1.0 或更高版本编辑和运行。

使用 `Get-FileHash -Algorithm SHA256 文件路径` 与 `SHA256SUMS.txt` 或对应 `.sha256` 核对。安装包尚未做数字签名。

发行包绑定同名源码标签 `v1.1.0`；包内 `runtime/release.json` 记录版本、源码提交、标签和构建地址。
