# EchoTest 1.2.0

本版加入安卓设备自动化，升级 Python 编辑器，并整理连接、录制和执行界面。

## 安卓设备

- 支持 USB 与无线调试连接真机和模拟器，内置 ADB，无需单独安装 Android SDK。
- 使用实时视频展示设备画面，通过持续控制通道发送单击、长按、滑动、系统导航和 ASCII 文本输入；提供视频帧率、分辨率及码率设置。
- 录制工作台发出的安卓操作，生成用例并支持重放；运行或重放自动进入设备画面页，显示执行进度和结果。
- 采集安卓原生 UI 控件树，按资源 ID、文字、无障碍描述等属性定位，支持等待、存在和消失验证，并复用共享控件库与 Python 接口。
- 图片模板和 OCR 定位继续适用于安卓；附加模板可重命名并预览。
- 修复首次连接后返回、主界面、多任务按钮未及时启用，以及连接和输入链路的延迟问题。

## 编辑与界面

- 集成本地 Python 编辑器及语言服务，提供代码补全、诊断、格式化和中文界面。
- 新增「设置 → 环境设置」，统一管理 ADB、安卓视频参数并查看运行依赖。
- 精简页面标题、重复录制按钮、预览模式选择及底部状态栏；断开设备使用红色按钮。
- 录制页说明更新为「人工录制操作路径以快速形成用例雏形」。

## 安装与交付

- 使用白色中文安装向导，支持安装、升级与卸载时保留用户用例及控件数据。
- 最新构建放在 `dist/latest/`，旧构建按版本和时间保留到 `dist/history/`。
- 提供 Windows x64 安装包、离线便携包及 SHA-256 校验文件。

安卓原生 UI 采集依赖应用实际暴露的控件。Unity 等自绘游戏的内部控件树尚未接入；可继续使用图片 / OCR 定位。MCP 当前仍用于 Windows 目标。安装包未做数字签名。
