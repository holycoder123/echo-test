# 工作台设置

侧边栏打开「设置」。修改后点击「保存设置」生效；「重置本组」只重置当前分类，仍需保存。配置位于 `%APPDATA%/echo-test/settings.json`，不随仓库和发行包分发。支持导入预览、保存后应用，以及导出当前已保存配置；导出不包含 MCP 凭据。

| 分类 | 设置 |
| --- | --- |
| 快捷键 | 运行 F6、录制 F7、截图 F8、指选 Ctrl+Alt+W、显示工作台 Ctrl+Alt+E、停止 F12；可重设或清空非停止项 |
| MCP | 启停本机接口、查看监听状态、复制连接配置、重置连接凭据、默认探索超时 1～30 秒 |
| 启动与关闭 | 默认请求管理员权限、记住工作台位置大小、关闭时退出或隐藏到托盘 |
| 目标窗口 | 默认指选/搜索、自动刷新间隔或关闭刷新、默认搜索条件、连接后打开工具栏、默认捆绑工具栏 |
| 报告与日志 | 按 7/30/90/180/365 天预览并手动清理历史，显示报告占用和预计释放空间 |

快捷键为全局快捷键；录入组合键时暂时释放已有配置，避免触发旧操作。重复组合、系统中已被占用的组合及与 F1、Ctrl+S、Ctrl+Shift+S 冲突的组合会阻止保存；冲突时恢复原绑定。F12 在录制、执行和指选期间始终保留为停止键，可另设一个停止组合键。

管理员权限设置下次启动生效，显式 `--admin` / `--no-admin` 参数优先。权限设置同时适用于 start.cmd、Python 启动入口和 Electron 直接启动。记住位置会校验屏幕范围，避免恢复到已断开的显示器。

MCP 开关立即生效，运行或录制期间需先停止。重置连接会使旧客户端凭据失效，需要重新连接。默认探索超时只用于未传入 `timeout` 的 `echo_test_explore` 调用；显式参数优先。使用 `--disable-mcp` / `--no-mcp` 启动时，本次会话禁止开启 MCP，正常重启后恢复设置中的开关。

窗口列表刷新不会自动连接或激活其他窗口。默认捆绑设置在下次连接目标时生效。

清理不会自动执行。先保存保留期限，再预览删除范围和空间并确认；确认时重新核对候选记录，不删除预览后新产生或更新的报告。每批最多 1000 份已完成报告及最近 1000 条诊断日志，异常路径会跳过。测试用例、通用控件、录制数据及当前编辑内容保留。
