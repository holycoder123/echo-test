# Python 编辑体验升级

用户已选择先做完整编辑体验：高亮、补全、参数提示、错误标记、格式化、跳转与查找；断点调试留到后续阶段。

**设计：** 保持白色简约主题，使用 Monaco 替换现有 Python 文本编辑框。用例编辑区、步骤展开编辑、只读生成预览使用同一编辑器适配层；右侧控件面板保留，底部显示问题列表与光标位置。编辑模型独立于页面 DOM，连接状态变化或切页不丢撤销、选区和滚动。F12 保持紧急停止，Ctrl+B 跳转定义，Ctrl+Alt+L 格式化。

**架构：** 本地打包 Monaco ESM 与 worker，禁止依赖 CDN。Electron 主进程管理 Pyright 子进程，通过限制过的方法桥接补全、参数、悬浮、诊断和跳转；补充工作台运行时全局变量类型，诊断/位置映射回原代码。Ruff 使用现有内置 Python 环境执行格式化，不执行用户脚本。编辑分析与实际运行隔离。
