# EchoTest 白色简约安装向导

用户已确认可点击预览并要求按该风格接入真实安装器。

- 白底、浅灰步骤区和页脚、深色主按钮、现有 EchoTest 标识。
- 四步：欢迎、安装选项、真实安装进度、完成。安装期间不能跳步；不把预览模拟逻辑用于真实安装。
- 安装选项包含安装目录、桌面快捷方式、MCP 启动快捷方式；回退后保留选择。
- 欢迎页说明离线依赖与升级前关闭工作台。完成页允许启动程序；测试与静默安装均不自动启动。
- 复用 NSIS 解压、注册表、运行中检查与用户数据保留；静默参数 /S /TESTINSTALL /NOSHORTCUTS /D= 保持兼容。
- 原生 Win32 界面，无浏览器及用户侧新增运行时。编译期使用固定版本和校验值的 TinyCC，生成 x86 UI DLL，由 NSIS 加载。
- NSIS 原生模板资源经 Python 标准库生成并注入。C DLL 仅绘制窗口/按钮/步骤及处理窗口交互，不负责安装文件操作。
- 版本仍为 1.1.0；不发布、不覆盖之前的正式构建，新的本地产物使用独立命名。
- 验证原生窗口、选项记忆、目录阻止、静默安装/覆盖升级/卸载保留数据，以及当前真实 100% DPI。150% DPI 需在对应桌面缩放下另测，不用伪造参数代替。

本地 control_library 修改与已有未跟踪文档均不得覆盖或提交。
