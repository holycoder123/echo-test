# 侧边用例编辑器与 Python 控件预览

用户已确认执行：选择桌面窗口后，原工具栏成为可调整宽度的侧边用例编辑器；采集控件后默认追加单击；支持生成 Python 副本；Python 提供代码行下的图片预览开关且保持可编辑。

## 数据与窗口

主工作台的当前用例保持唯一权威状态。侧边窗口接收版本化快照，并发送受限的编辑指令，由主工作台串行处理。过期指令拒绝执行并保留侧边草稿，避免覆盖另一窗口的新修改。主工作台的未保存提示、运行锁定、共享控件稳定 ID、另存为规则继续生效。

侧边保留现有录制、执行、用例选择、捆绑与停止能力，增加步骤列表、参数、保存、Python 转换与返回低代码原稿。步骤列表在有限宽度内滚动，Python 和参数面板可折叠，既有操作入口不被挤出屏幕。

## 采集

侧边可采集图片和坐标。采集时暂时隐藏工作台及侧边窗口，使用现有目标截图接口；失败也恢复窗口。框选完成在侧边命名和确认，保存到共享控件库后引用到当前用例。低代码在所选步骤后追加单击；Python 在光标处插入 `window.click(controls.by_id("稳定ID"))`。取消不产生控件或步骤。采集中切换目标或用例时拒绝过期结果。

## Python

复用现有生成代码、独立副本和低代码原稿恢复能力，任意 Python 修改不自动逆向转换。侧边使用同一本地 Monaco 编辑器和语言服务，保留保存、停止和锁定行为。

“控件预览”是编辑器显示选项，不修改源码、用例脏状态、导出或执行。通过静态解析 Python 提取直接的 `controls.by_id("id")`、`controls["名称"]` 以及简单变量赋值引用。用行下视图区显示控件名、类型和模板缩略图，点击查看大图；坐标和原生控件显示名称及类型。动态引用或缺失控件明确提示，不执行代码来求值。语法不完整时不破坏编辑；模型更新后丢弃旧版本的异步预览结果。重渲染和关闭须释放视图区和监听器。

## 验收

- 主窗口和侧边编辑同一用例，互相更新；并发过期操作不会静默覆盖。
- 图片/坐标采集、取消、命名、默认单击、已选步骤后插入及 Python 光标插入通过实际界面检查。
- 保存、另存为、Python 副本和低代码原稿恢复、运行停止、F12、录制和目标解绑继续可用。
- 预览直接引用与简单变量、动态/缺失引用、图片加载失败、编辑和开关切换、重渲染、模型旧请求均验证。
- IPC 严格限制窗口角色，不开放安卓配置、设置清理或任意后端指令。
- 使用隔离 UI profile，不操作用户应用或设备；本次不构建安装包、不发布版本。
