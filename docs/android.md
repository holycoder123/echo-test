# 安卓设备接入（首版）

EchoTest 可在 Windows 工作台连接安卓真机或模拟器，通过 ADB 获取画面、操作设备、录制预览中的操作，并复用现有用例编辑、安卓原生 UI / 图片 / OCR 定位、执行报告。入口为左侧「安卓设备」。

## 内置 ADB

安装版和便携版均内置 ADB 37.0.1 及其运行依赖，正常使用无需安装 Android Studio、Android SDK、Appium 或 Java。可在「设置 → 环境设置」查看 ADB 来源与实际路径。手机端仍需开启 USB 调试并允许电脑授权；个别厂商的 USB 驱动由 Windows 或厂商提供。

工作台默认使用 `runtime/android/platform-tools/adb.exe`。手动选择的路径和 `ECHO_TEST_ADB` 可覆盖默认值；也兼容 `ANDROID_HOME` / `ANDROID_SDK_ROOT` 下的 `platform-tools`、用户目录的 Android SDK 和系统 PATH。「设置 → 环境设置」的「更换 ADB」选择自己的版本，「恢复自动」取消手动路径，均在保存后生效。配置统一保存在本机 `settings.json`，兼容读取旧的 `android.json`；修改前需先断开设备。旧路径失效时回退到自动检测。

构建时，`scripts/vendor-adb.py` 从 [Android 官方 Platform-Tools](https://developer.android.com/tools/releases/platform-tools) 固定版本地址获取压缩包，并校验 SHA-256。包内只保留 ADB、运行 DLL、版本信息和原始 `NOTICE.txt`，不包含 fastboot 等无关工具。版本、下载来源和文件哈希记录在 `runtime/android/manifest.json` 及总运行环境清单中。下载缓存位于 `.runtime/android-build`，后续重建可直接使用已校验缓存。

源码开发环境可运行 `node scripts/python.cjs scripts/vendor-adb.py` 准备内置 ADB；打包脚本会自动执行这一步。若发行包中的 ADB 文件丢失，重新安装完整 EchoTest 即可恢复，也可以手动选择完整 [Platform-Tools](https://developer.android.com/tools/releases/platform-tools) 目录中的 `adb.exe`。

## 连接设备

1. 在手机开发者选项中开启 USB 调试，使用数据线连接电脑。
2. 解锁手机，确认「允许 USB 调试」授权。Windows 若无法发现设备，需检查线缆及对应厂商的 USB 驱动。
3. 打开「安卓设备」，点击「刷新设备」，选择状态为「可连接」的设备。
4. 连接成功后显示设备画面。工作台同一时间选择一个执行目标；连接安卓后会解绑桌面窗口工具栏，连接桌面窗口则断开工作台中的安卓目标。

已启动并能在 `adb devices -l` 中看到的模拟器也会出现在列表中。未授权、离线设备会显示原因，并禁止连接。

Android 11 及以上无线调试：手机和电脑在同一网络，在手机「无线调试 → 使用配对码配对设备」查看配对地址、端口和六位配对码，填入设备页「无线调试」并配对。随后填写无线调试主页的**连接地址和端口**，点击「连接无线设备」，刷新列表并选择该设备。配对端口与连接端口通常不同；配对码不会保存到应用配置。

Android 10 及以下可先用 USB 连接，手动通过 `adb -s <序列号> tcpip 5555` 启用 TCP/IP，再填写 `设备IP:5555` 连接。工作台不会自动更改手机的 TCP/IP 调试设置。详见 [ADB 官方连接说明](https://developer.android.com/tools/adb)。

## 操作和录制

- 默认使用「流畅视频」：内置 scrcpy server 采集手机 H.264 视频，经 ADB 隧道传到 Electron，通过 WebCodecs 解码后直接绘制在设备页。默认帧率上限 30 FPS、最长边 1280、码率 4 Mbps，可在「环境设置」调整，下次连接画面生效；静止画面会减少帧数，实际帧率取决于内容、手机编码能力和连接质量。视频帧按最新画面显示，限制待处理队列，避免长时间累积延迟。
- 视频组件和许可随安装版、便携版提供，无需另装 scrcpy 或 FFmpeg。首次预览向手机的 `/data/local/tmp/` 推送临时视频服务，通过调试权限运行；不会安装 APK，也不需要 root。断开设备、离开设备页、隐藏页面或关闭工作台时停止视频连接并清理本次转发。
- 连接时只检测设备并读取尺寸，直接启动视频，不再连续获取两张完整截图。流畅模式的触控、导航按键和文本使用 scrcpy 独立的持久控制连接，不经过 Python 截图队列，也不逐次启动 `adb shell input`。状态栏显示「实时触控」后即可操作；剪贴板同步和自动唤醒手机均关闭。
- 连接后自动显示实时视频，不再提供预览模式下拉框或实时预览复选框。「重连画面」重启视频；连接或解码失败时显示原因并停止预览，可手动重连，不回退到定时截图。旧版保存的截图预览偏好会自动忽略，其他环境设置保留。
- 流畅模式按下即发送触点，移动持续发送，松开立即释放，不在松开后重放手势。移动事件按画面刷新合并，按下 / 松开保持顺序。按住至少 0.5 秒记为长按，最长 10 秒自动释放；Esc、失焦、取消指针、停止、切换画面和断开均释放当前触点。旋转 / 视频配置变化时同步新的坐标空间后重新允许触控。
- 「返回」「Home」「最近应用」发送对应系统按键。文本框用于发送 ASCII 可打印字符，流畅模式每次最多 4096 字符，按协议分块发送；中文需先在手机上输入。
- 填写应用包名，如 `com.example.app`，可启动已安装且有 Launcher 入口的应用。
- 点击「开始录制」后，预览点击、长按、滑动、系统按键和文本输入会转换为步骤。实时手势在松开并提交后生成一个步骤，不再次操作手机；取消的手势不生成步骤。记录原始手势时间，避免后端排队改变录制间隔。停止或按 F12 后等待已提交记录写入，再保存本段。只记录工作台提交的操作，不采集在手机屏幕上直接进行的手指操作；控制协议不提供逐次输入执行确认。
- 录制位置保存为屏幕比例坐标；流畅模式在横竖屏变化后自动同步并取消旧手势。已有录制发生画面尺寸变化时，请结束本段后重新录制。

## 安卓原生 UI 控件

在设备画面下方点击「采集 UI 控件」，读取手机当前界面的控件树。可搜索资源 ID、文字、无障碍描述、类名和包名；选择节点查看属性与边界，点击「使用所选控件」后命名并保存到通用控件库。控件编辑器也提供「安卓 UI」定位方式，可手动调整条件，并通过「预览定位」查看当前匹配框。

定位使用系统自带的 UI Automator，通过现有 ADB 连接按需读取，无需安装手机端 APK、Appium 或额外 Java。采集默认优先保存资源 ID 与包名；缺少 ID 时使用描述、文字或类名。所有已填写条件同时精确匹配，可附加可点击 / 启用状态。匹配多个节点会报错，需增加条件或指定从 1 开始的匹配序号；序号为 0 时要求唯一匹配。界面结构变化后，应重新检查使用序号的控件。

原生控件可用于单击、双击、长按、拖动起终点和滚动，并新增「等待安卓控件」「安卓控件存在」「安卓控件不存在」步骤。存在与等待会持续定位到出现或超时；不存在会等待至一次成功读取确认控件消失。读取失败、断线或超时均会报错，不会当作控件不存在。每次定位重新读取当前界面，点击前校验画面方向；原生控件不能在 Windows 目标执行。

读取控件树通常需要数秒，界面持续动画时可能等待或失败。采集不进入视频或手动触控链路；新增步骤默认选中原生控件时，定位超时为 15 秒，可按设备调整。游戏、自绘界面、部分 WebView 等可能只暴露容器，内部按钮仍需图片 / OCR 定位。首版不提供 WebView DOM、XPath 或后台持续扫描。

Python 用例支持 `window.locate(controls["登录"])`、`window.click(controls["登录"])`、`window.wait_ui(controls["登录"], timeout=15)`、`window.assert_ui(...)` 与 `window.assert_ui_absent(...)`。低代码生成的 Python 副本保留原生控件引用和等待 / 断言行为。

## 用例、识别与报告

设备页可采集图片或坐标控件；通用控件库中的 OCR 文字控件也可用于安卓截图。图片模板、多模板、遮罩、锚点、OCR、等待与断言使用同一个识别实现。图片模板仍需针对设备缩放、分辨率和实际界面校准，Windows 控件截图不会自动转换成安卓模板。

点击「运行当前用例」执行编辑器中的用例，或到用例页运行。安卓目标从用例页、快捷键或录制重放启动后，均自动进入「安卓设备」页面，显示设备画面与执行进度；重放完成后继续保留设备页面。运行时停止按钮和 F12 可取消后续步骤并终止等待中的 ADB 子进程；手动预览输入、切换设备和修改 ADB 配置会锁定。失败截图、识别诊断和步骤结果保存在现有报告目录，JSON 报告增加 `target.platform` 与设备序列号。

首版支持点击、双击、长按、直线拖动 / 滑动、滚动、截图、等待、断言和现有循环 / 变量。按键步骤可填写 `BACK`、`HOME`、`APP_SWITCH`、`ENTER` 等单个按键；鼠标右键、中键、键盘组合键、独立按下 / 松开按键和曲线拖动在运行前会被拒绝。Python 用例中的 `window` 调用使用所选安卓后端，但平台不支持的操作仍会报错；生成的独立 Windows 脚本暂不作为安卓执行入口。

当前 MCP 工具仍用于 Windows 目标，不支持通过 MCP 控制安卓。安卓连接与操作通过本地工作台进行。

## 验证

`tests/test_android_ui.py` 覆盖控件树边界、精确匹配与重复节点、读取失败与取消、控件库存储、定位执行及脚本接口。`android-smoke.json` 增加首次连接无需切页启用导航按钮、UI 采集 / 保存 / 预览与原生断言选择检查。

`tests/test_android.py` 使用模拟 ADB 验证设备状态、地址与参数校验、进程超时 / 取消、截图、坐标、输入、录制、真实执行器、图片匹配 / OCR 分流、报告与停止。`npm run test:ui` 中的 `android-smoke.json` 验证设备页面、授权状态、缩放坐标映射、录制请求、图片采集和目标绑定，不向真实设备发送输入。

实机验收：连接一台已授权手机，完成点击、长按、滑动、返回、录制后重放、采集图片并运行断言；再检查拔线、横竖屏变化与 F12 停止。无线配对需使用手机显示的当前端口实测。
